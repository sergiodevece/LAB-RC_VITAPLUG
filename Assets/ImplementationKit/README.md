# LAB-RC — Paquete de implementación 1.0
Descomprimir en directorio local y abrir con Codex. Entregar `MASTER_PROMPT.md` como tarea, manteniendo la estructura. La maqueta vintage es referencia de estilo; las tres imágenes de `assets/rooms` son escenas aprobadas. Las IR v05 fueron aprobadas por el usuario mediante escucha; las v06 aún no han sido probadas en plugin. No se incluye código C++ ni ejecutable. Este paquete contiene datos de implementación, no los laboratorios completos reproducibles; conservar los ZIP AcousticLab v03–v06 aparte. `python -m pip install numpy scipy` en un entorno virtual si no están disponibles, luego `python verify_assets.py`. No publicar ni distribuir antes de revisar permisos y licencias. El informe histórico de investigación conserva sus estados anteriores, no contradice la aprobación posterior del usuario. Los nombres, controles y límites de este documento son propuesta de implementación salvo las referencias sonoras/visuales ya aprobadas.
